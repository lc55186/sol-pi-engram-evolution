## 二、"多外脑"角色系统 PRD

### 2.1 角色定义

基于 NBBOSS 多外脑 + WorkBuddy 专家体系 + BOSS-AI-R 谈判场景，设计以下角色：

| 角色 | 代号 | 核心能力 | 知识库 | 触发条件 |
|------|------|---------|--------|---------|
| 谈判专家 | `negotiator` | 谈判策略、让步分析、BATNA 计算 | 谈判心理学/定州产业行情 | 检测到谈判语境 |
| 心理分析师 | `psychologist` | 对方情绪识别、意图推断、压力点判断 | 微表情/语调/用词模式 | 对方发言时自动激活 |
| 财务顾问 | `cfo` | 成本核算、利润分析、付款条件评估 | 企业财务/税务规则 | 涉及价格/付款话题 |
| 法务顾问 | `legal` | 合同风险、条款审查、合规检查 | 合同法/行业法规 | 涉及合同/承诺话题 |
| 行业顾问 | `industry` | 定州三大产业（汽车零部件/体育器材/再生资源）行情 | 产业数据库/供需信息 | 涉及产品/供应链话题 |

### 2.2 角色切换逻辑

```
触发方式:
1. 自动切换: ASR 实时识别关键词 → 路由到对应角色
2. 手动切换: 用户双击耳机/手表按钮 → 循环切换角色
3. 混合模式: 主角色(谈判专家)常驻 + 辅助角色按需弹出

切换延迟目标: < 200ms (用户无感知)
```

### 2.3 知识隔离设计

- 每个角色独立知识库，互不污染
- 共享层: 用户画像、历史谈判记录、企业基本信息
- 隔离层: 角色专属 Prompt、行业数据、分析框架
- 冲突处理: 多角色意见不一致时，主角色(谈判专家)做最终裁决

### 2.4 订阅定价建议

| 套餐 | 年费 | 包含角色 | 目标用户 |
|------|------|---------|---------|
| 免费版 | 0 | 谈判专家(基础版) | 体验用户 |
| 专业版 | 980 | 谈判专家 + 心理分析师 | 个体老板 |
| 旗舰版 | 6,800 | 全部 5 个角色 | 中小企业 |
| 企业版 | 29,800 | 全部角色 + 定制行业顾问 + API | 规模企业 |

### 3.2 推荐接入策略

**Phase 1 (2026 Q4): 钉钉智能体应用**
- 理由: 钉钉开放平台有专属 AI 开发套件，Agent 自动连接，一键创建智能体应用

- 成本: 钉钉 PaaS 资源限时免费(至 2026.3，需确认延期)

**Phase 2 (2027 Q1): 飞书 AI 助手**

- 对接方式: 飞书开放平台 Bot API + H5 应用
- 场景: 团队协作版谈判辅助（多人协同准备、实时共享情报）

**Phase 3 (2027 Q2): 企业微信接入**
- 理由: 定州传统制造业老板多使用微信生态
- 对接方式: 企业微信 API + 微信小程序
- 场景: 轻量版谈判辅助（微信内直接使用）

## 四、RK1860 硬件路线更新

### 4.1 RK1860 关键参数确认

| 参数 | 值 |
|------|-----|
| 芯片型号 | RK1860 (瑞芯微新一代 AI 协处理器) |
| 算力 | 60-80 TOPS (INT8) |
| 架构 | 3D 架构协处理器 |
| 支持模型 | 13B 参数级别 |
| 内存 | 2.5GB / 5GB / 10GB LPDDR 扩展 |
| 发布时间 | 2026 Q2 (已发布) |
| 定位 | 端侧驱动 13B 级别大模型 |

### 4.2 对 SoL-Pi 部署路线的影响

**当前方案**: RK3588 + RK1828 双芯
- RK3588: 主控 + 6 TOPS NPU
- RK1828: AI 协处理器

**升级路径**: RK3588 + RK1860
- RK1860 算力(60-80 TOPS) 远超 RK1828
- 可运行 13B 级别模型（RK1828 仅支持 7B 以内）
- 3D 架构带来更好的能效比

**建议**:
1. **短期 (2026 Q4)**: 继续用 RK3588 + RK1828 方案，已验证可用
2. **中期 (2027 Q2)**: 评估 RK1860 开发板，测试 13B 模型端侧推理
3. **长期 (2027 Q4)**: 若 RK1860 成本下降，切换为 RK3588 + RK1860 方案
