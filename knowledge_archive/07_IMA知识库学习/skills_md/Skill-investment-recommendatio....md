# 💼 投资推荐增强技能 — 让推荐理由完整可解释

## When to Use

激活此技能的条件：

* 用户要求"给出推荐理由""说明为什么买""写出买入动机"或类似表达
* 投资/股票分析报告需要展示决策逻辑，而非仅输出代码和目标价
* 交互式推荐引擎生成结果时，希望每个标的包含完整的分析维度
* 回测策略需要记录并展示每次推荐的决策依据

**不要触发于**：仅要求"列出股票代码"、"返回原始数据"、"只给价格目标"等不需要解释的场景。

## Prerequisites

* 标的基本信息：当前价、涨跌幅、换手率、PE、所属概念/赛道
* 策略类型：短线7天 / 长线1-3月

## Procedure

### Step 1 — 收集核心指标

提取标的的基础量化数据：

```python
core_metrics = {
    'price': float(data['current_price']),
    'change_pct': float(data['change_pct']),
    'turnover': float(data['turnover_rate']),
    'pe': float(data['pe_ratio']),
    'sector': data.get('sector', ''),
    'strategy': 'short' if is_short_term else 'long'
}
```

### Step 2 — 构建事件驱动列表

按顺序检查以下因子，每项满足即加入驱动列表：

| **因子** | **触发条件**              | **示例表述**           |
| ------ | --------------------- | ------------------ |
| 概念热度   | sector 非空             | "所属概念/赛道：AI算力"     |
| 资金活跃   | turnover > 5%         | "换手率 6.2%，资金高度活跃"  |
| 估值合理   | 0 \< PE \< 30         | "PE 24.8 处于合理偏低区间" |
| 温和上涨   | 0 \< change\_pct ≤ 3% | "涨幅 1.8%，动能充足"     |
| 回调低吸   | -3% ≤ change\_pct ≤ 0 | "回调 2.1%，低吸窗口期"    |
| 策略匹配   | 所有情况                  | "短线7天策略：追求动量+资金共振" |

### Step 3 — 确定买入动机总结

根据策略类型得出核心动机：

**短线策略：** change\_pct > 0 且 turnover > 3% → "动量+资金共振，短线突破窗口"；change\_pct \< 0 → "回调低吸，博弈反弹"；其他 → "概念热度驱动，顺势而为"。

**长线策略：** 0 \< PE \< 30 → "低估值+高景气赛道，长期配置价值突出"；change\_pct \< 0 → "赛道回调，长期布局良机"；其他 → "赛道景气度向上，长期持有逻辑不变"。

### Step 4 — 计算建议价格区间

基于当前价 P：激进 = P × 1.01，稳健 = P，保守 = P × 0.97。同时计算止损位、目标价、风险收益比。

### Step 5 — 组装完整推荐报告

合并 event\_drivers、buy\_motivation、price\_zones 到每条推荐记录。

## Pitfalls

| **坑**  | **Fix**           |
| ------ | ----------------- |
| 动机模板化  | 按不同指标组合输出不同摘要     |
| 价格区间异常 | 保守价不超过当前价 3%      |
| 事件堆砌   | 最多选取前 3 个最具决定性的因子 |

## Verification

- [ ] 完整性：每条包含 event_drivers、buy_motivation、price_zones

- [ ] 一致性：短线止损 ≤5%，长线止损 ≤10%

- [ ] 可读性：买入动机总结语句通顺独立成句

- [ ] 数值合理：激进 ≥ 稳健 ≥ 保守 递减

- [ ] 事实准确：数值来自原始数据

Verdict: READY / UNSURE / BLOCKED
